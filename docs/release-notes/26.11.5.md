## Before you upgrade

- `THESADA_BASE_URL` must be an absolute URL with scheme and host (`https://app.example.com`). A relative value now stops the app at boot.
- Devices need firmware 1.4.5 or later, the first that echoes the request id. File saves and rule pushes to older or unknown firmware are refused with a 409, and drift pulls skip them. A `config.json` save that leaves a secret field empty also needs `secret.info` on the device, which firmware 26.07.1 and later answer. Older firmware gets that save refused, nothing is sent.
- Self-host: `deploy/startup.sh` needs Docker Compose 2.17 or newer and stops on an older one.
- Rolling back to 26.11.4 needs no SQL. See "Roll back the app" in `docs/runbook.md` for what 26.11.4 does with data this release wrote.
