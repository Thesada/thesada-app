## Before you upgrade

- `THESADA_MQTT_URL` must use `tcp://`, `mqtt://`, `tls://`, `ssl://` or `mqtts://`, or no scheme (read as `tcp`). A `ws://`, `wss://`, `unix://` or other scheme now stops the app at load with an error naming the variable.
- Self-host: compose moves timescaledb to `2.32.1-pg17` and mosquitto to `2.1.4-alpine`. `deploy/startup.sh` updates the timescaledb extension on start, and that update cannot be undone. Take a database backup first.
- No new migrations. Rolling back to 26.11.5 needs no SQL.

## What changed

| Area | Change |
|---|---|
| Web | Light, dark and system theme under Settings, Appearance. The choice is stored per browser and applies before the page paints. The device chart and the offline page follow it |
| Web | On a phone the header and the iOS status bar stay dark and the header email is brighter. Wide tables in cards scroll sideways instead of wrapping each cell. A channel email no longer breaks per character |
| Sign-in | A logged-out visit to a page that needs a login, a device claim link included, comes back to that page after a password or SSO login, through the TOTP and passkey steps too. A magic-link login lands on Devices. Off-site return targets are dropped and the login lands on Devices. A login that was given up on never sends a later one to its page |
| Devices | Firmware that masks secrets on reads (`(set)`, `(empty)`) works next to firmware that does not. A marker is never stored or sent as a secret value, and the Secrets page refuses one. A masked dump of an unchanged config counts as in sync. A save whose rename reply timed out reads the file back masked too, also when the masked copy keeps its size, and compares integers exactly. Its write claim lasts for both masked reads |
| Devices | A config write or command after a bulk OTA keeps its 15 minute config window. A confirmed `config.json` write inside that window is not stored as a device read, Load from device after the window refreshes it |
| Devices | A `config.json` with anything after the JSON object is refused |
| Rules | An operator rules save can no longer overwrite a tenant editor save that landed in between. The operator gets a 409 and saves again |
| Self-host | The compose file pins this release |
| Dependencies | OpenTelemetry 1.47.0 (GHSA-q7gw-24fr-5p69). gorilla/websocket stays at 1.5.3: GO-2026-6278 affects only websocket clients, and the one client path in the app, an MQTT broker over `ws` or `wss`, is refused at load |
